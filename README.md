# Lunoa Concierge

> **あなたのAndroidに、いつでもそばにいるコンシェルジュを。**

Lunoa Concierge（ルノア コンシェルジュ）は、Androidスマートフォンをもっと快適に使うためのパーソナルコンシェルジュアプリです。

単なるAIチャットではなく、ホームランチャー、アプリ操作、通知、Web検索、ルーティン、NFCオートメーションなど、日常的なスマートフォン操作をひとつにつなげることを目指しています。

**Latest: v1.0.1 / Android 8.0+ / 広告なし**

[公式LP](https://automationseDev.github.io/LunoaConcierge/) ・ [Releases](https://github.com/automationseDev/LunoaConcierge/releases) ・ [要望・不具合・問い合わせ](https://github.com/automationseDev/LunoaConcierge/issues)

## 主な機能

- **パーソナルホームランチャー** — お気に入りアプリを最大16個登録。スマートなアプリ一覧にも対応。
- **AI会話 / Web検索** — 利用者が設定したAIサービスを使って会話や情報検索。
- **フローティングコンシェルジュ** — 他のアプリ上からLunoaへアクセス。
- **通知案内** — 許可した通知をLunoaの吹き出しとして端末上で表示。
- **Webページ要約** — 閲覧中ページの概要把握を支援。
- **NFCオートメーション** — NFCタグから複数アクションやシーンを実行。
- **ルーティン / Concierge Hub** — 通知・おすすめ・日常操作をまとめて管理。
- **Galaxy Z Fold対応** — 折りたたみ・展開・マルチウィンドウに合わせてUIを調整。

## セキュリティ / プライバシー

- 通知案内は端末上で処理し、通知案内のためだけに外部AIサービスへ送信しません。
- Web検索モードなど、外部AIを使う機能では利用者自身が設定したサービスへ情報を送信する場合があります。
- GitHub Issueへ秘密情報・APIキー・アクセストークンを投稿しないでください。
