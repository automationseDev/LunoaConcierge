FEATURES

日常のAndroid操作を、Lunoaへ。

ホーム画面から通知、検索、オートメーションまで。必要な機能へ迷わずアクセスできます。

⌂

パーソナルホームランチャー

お気に入りアプリを最大32個登録。設定から表示数を1〜32個で変更でき、アイコン間隔も5段階で調整できます。スマートなアプリ一覧と組み合わせて、普段のホーム画面そのものをLunoaにできます。

✦

AI会話・Web検索

利用者が設定したAIサービスを使って会話や情報検索。必要なときにLunoaへ話しかけるだけ。

◉

フローティングLunoa

他のアプリを使っている最中もコンシェルジュを呼び出せます。アプリ一覧は用途別のカテゴリと件数付きで整理され、目的のアプリをすばやく見つけられます。

◌

通知案内

許可したAndroid通知をLunoaの吹き出しで案内。通知案内のためだけに外部AIへ内容を送信しません。

⌁

NFCオートメーション

NFCタグから複数アクションやシーンを実行。日常の繰り返し操作をタグひとつにまとめられます。

▤

ページ要約・情報収集

閲覧中のWebページを要約し、ニュースや情報を効率よく確認。長いページの概要把握にも使えます。

◇

Concierge Hub / ルーティン

通知・おすすめ・ルーティンをまとめて管理。状況に合わせた操作へスムーズにつなげます。

▰

Galaxy Z Fold対応

折りたたみ、展開、マルチウィンドウなど、画面サイズが変化する端末でも使いやすいUIを目指しています。

ONE APP, ONE EXPERIENCE

広告なし。すべて同じLunoa。

Lunoa Conciergeは広告を表示せず、すべての利用者が同じ機能を利用できます。毎日のホーム画面やコンシェルジュ体験を、シンプルに気持ちよく使えることを大切にしています。

✓ 広告表示なし✓ すべての利用者が同じ機能✓ 任意の開発サポート✓ 継続的にアップデート
UPDATE EXPERIENCE

更新も、Lunoaらしく。

新しいバージョンが見つかると、更新内容をカードUIで確認できます。その場で「アップデート」「今回はしない」を選べます。
